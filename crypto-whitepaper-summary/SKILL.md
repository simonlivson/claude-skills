# Crypto whitepaper summary

Produce a one-page research note with exactly these sections:

1. **What it is**: two sentences on the problem and the solution, in plain words.
2. **How it works**: chain, consensus or architecture, and anything new (e.g. ZK, MPC, bridges).
3. **Token model**: token name, total supply, allocation (team, investors, community), vesting, and what the token is used for.
4. **Team and backers**: named founders, prior work, and investors, only as stated in the source.
5. **Risks**: at least three, such as token unlocks, centralization, regulation, smart-contract or bridge risk, unclear revenue.
6. **Verdict**: one line on what to check next before investing.

Rules:
- Use only facts from the provided document; write "not stated" when something is missing.
- Quote numbers exactly as the document gives them.
- End with: "Not financial advice."
